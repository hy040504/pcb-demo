# CircuitEye (써킷아이) 데모

PCB 외관검사 웹 MVP의 UI 시안(단일 HTML)입니다. 실제 서비스가 아니며 모든 데이터는 가상입니다.

## 샘플 이미지 출처

데모의 PCB 사진은 공개 데이터셋입니다. 의심 영역 박스는 각 데이터셋의 정답 위치로 표시한 시연 값이며 실제 AI 결과가 아닙니다.

- **VisA PCB1** — Zou et al., *SPot-the-Difference Self-Supervised Pre-training for Anomaly Detection and Segmentation*, ECCV 2022. CC BY 4.0 (`docs/assets/samples/LICENSE-VisA-CC-BY-4.0.txt`).
- **DeepPCB** — Tang et al., *Online PCB Defect Detector On A New PCB Defect Dataset*, 2019. 원 저장소 기준 **연구용으로만** 사용 가능합니다.

자세한 내용: `docs/assets/samples/README.md`
